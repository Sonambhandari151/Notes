###### Layer 6
Responsible for data transmission and encryption.
Formats the data to be exchanged and secures that data with proper encryption.

#### Data formatting 
Data is formatted by the computer to have compatibility between different devices.
- ASCII 
- UTF 8
- GIF
- JPG
- PNG

and based on the different data formats that is being used the computer knows how to render it or show it on screen.

All these file format comes down to 0 and 1


It is important to mention that the sent data is ASCII because the receiver computer may interpret the data as Utf 8 encoding so how would it know that the sent data is ASCII

#### Encryption
Used to scramble the data in the transit to keep it secure from the prying eyes and provide data confidentiality.

TLS/ (Transfer layer security) is used encrypt data that is being transmitted back and forth between a web browser  and web server.

SSL (Secure Socket Layer)
it creates an encrypted tunnel to securely transfer credit card info, user credentials etc

#### Scripting language
Scripting language like HTML, JS, php is also a layer 6 thing because it controls how the data will render in a webpage. It tells a text based ascii like bold italic underline to appear beautifully.
