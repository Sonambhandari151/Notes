OSI -> Open Systems Interconnection OSI Model OSI Stack
Developed in 1977 by International Organisation of Standardisation.

This organisation is responsible for creating different standards that we refer to ISO. For OSI Model it is ISO 7498 is for OSI Model.

There are 7 layers in OSI Model. OSI is often referred as OSI reference model.

#### Reference Model
because it provides a conceptual framework for understanding and designing network architectures and protocols
#### Purpose of OSI Model
1. Standardization: OSI Model standardizes network communication by dividing it into 7 distinct layer each responsible for specific function
2. Conceptual Framework: serves as a theoretical guide to understanding how different network protocols interact and work together.
3. Layered Approach: breaking down network communication into seven layers
   the OSI model helps in isolating and addressing issues in specific layers without affecting the others. Each layer has its own distinct function and interfaces with the layers directly above and below it.
