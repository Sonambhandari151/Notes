## Wifi Networks
- Wireless standards for LANs use the 2.4 GHz and 5 GHz frequency bands. 
-  Main organisation responsible for the creation of wireless technical standards is IEEE 802.11.
- Another organisation, **wifi alliance**, is responsible for testing wireless LAN devices from different manufacturers. The wifi logo on a device means that this equipment meets standards and should operate with other devices that use the same standard.


## Wireless Settings
- **Network mode:** determine the type of technology that must be supported. For eg. 802.11b, 802.11g, 802.11n or mixed mode.
- **Network name (SSID):** Used to identify the WLAN. All devices that wish to participate in the WLAN must have the same SSID.
- **Standard Channel:** Speicifies the channel over which communication will occur. By default , set to **Auto** to allow the access point (AP) to determine the optimum channel to use.
- **SSID Broadcast:** Determine if the SSID will be broadcast to all devices within range. By default, set to **Enabled.**
- **SSID: Service Set Identifier.**

The **802.11 protocol** determines the **Wi-Fi standard** used by devices in a wireless network. Throughput depends on the **environment** and the **Wi-Fi standard** being used.

### **Wi-Fi Standards and Compatibility**

- If all devices use the **same 802.11 standard**, maximum speeds for that standard are achieved.
- If the **access point supports only one standard**, devices using older standards cannot connect.
- A **mixed-mode environment** allows both **new and old** devices to connect but may reduce overall performance.

### **SSID (Service Set Identifier)**

- The **SSID** is the **name of a wireless network** (up to **32 characters**, case-sensitive).
- It is broadcast in all **Wi-Fi frames** to help devices identify and connect to the network.
- **Disabling SSID broadcast** hides the network but does **not** prevent unauthorized access.

### **Security Considerations**

- **Hiding SSID is not enough**; attackers can still detect it using sniffing tools.
- **Strong encryption (WPA2/WPA3)** should be used to prevent unauthorized access.
- **Manual SSID entry** is required if the SSID broadcast is disabled.

In short, **compatibility, performance, and security** must be balanced when configuring a **Wi-Fi network**.


## Set up a Home Router
### **How to Set Up a Home Wireless Router (Step-by-Step Guide)**

When setting up a wireless router for home use, you typically have two options: **wired** or **wireless configuration**. Here’s how the process works:

---

### **🔌 Wired Setup (Recommended for Initial Configuration)**

1️⃣ **Connect a Computer to the Router**

- Use an **Ethernet patch cable** to connect your computer to one of the **LAN ports** on the router.
- ❌ **DO NOT** connect to the port labeled **"Internet"**, as that port is for connecting to a DSL or cable modem.

2️⃣ **Verify the Physical Connection**

- Check that the **link lights** on the computer's network card (NIC) and router are blinking, indicating a working connection.

3️⃣ **Obtain an IP Address**

- Most routers have a **built-in DHCP server** that automatically assigns an IP address to connected devices.
- If the computer does **not** receive an IP address automatically, you may need to **manually configure**:
    - **IP Address** (Example: `192.168.1.100`)
    - **Subnet Mask** (Example: `255.255.255.0`)
    - **Default Gateway** (Router’s IP, e.g., `192.168.1.1`)
    - **DNS Servers** (Use ISP’s DNS or public ones like `8.8.8.8`)

4️⃣ **Access the Router’s Web Interface**

- Open a web browser and enter the router’s IP address (commonly `192.168.1.1` or `192.168.0.1`).
- Log in using the default credentials (found in the router manual).

---

### **📡 Wireless Setup (If No Wired Device is Available)**

- If a wired connection is not possible, you must first **connect to the router’s default Wi-Fi network** using a laptop, tablet, or phone.
- The default **Wi-Fi SSID and password** are usually printed on the router.

---

### **🔄 Internet Connection Setup**
### **🔌 Scenario 1: Using a Separate Modem (Most Common Setup)**

In this case, your **ISP provides a modem**, and you need to connect your router to it.

#### **Steps:**

1️⃣ **Connect the Modem to the Router**

- Use an **Ethernet cable** to connect the modem’s **LAN port** to the router’s **WAN (Internet) port** (usually labeled "Internet").

2️⃣ **Power On Devices in Order**

- First, turn on the **modem** and wait for it to establish a connection.
- Then, power on the **router** and let it boot up.

3️⃣ **Obtain an IP Address from ISP**

- The router should automatically **get a public IP address** from the ISP via **DHCP**.
- If required, log in to the router’s **web interface** (`192.168.1.1` or `192.168.0.1`) and check the **WAN settings**.

4️⃣ **Configure ISP Settings (If Needed)**

- Some ISPs require **PPPoE login credentials** (for DSL connections). Enter the **username and password** provided by your ISP in the router’s settings.
- If using **Static IP**, enter the details given by the ISP.
 
  ## Scenario 2: Router with a Built-in Modem
- If your router includes a built-in modem:
    - **Cable modem:** Connect the **coaxial cable** to the appropriate port.
    - **DSL modem:** Use an **RJ-11 telephone cable** to connect to the DSL line.
- If using an **external modem**, connect it to the **router’s "Internet" (WAN) port** via an Ethernet cable.

## Design Consideration

### What should my network be called?
If SSID broadcasting is on, the SSID name will be seen by all wireless clients within your signal range. Many times the SSID gives away too much information about the network to unknown client devices. It is not a good practice to include the device model or brand name as part of the SSID. Wireless devices have default settings that are easy to find on the internet, as well as known security weaknesses.

---
### What types of devices will attach to my network?
Wireless devices communicate using **Wi-Fi standards** (802.11). These standards determine **speed, range, and compatibility**. If a device does not support a specific standard, it **cannot connect** to a network that is restricted to that standard.


### **📡 Wi-Fi Standards & Compatibility**

| Standard               | Frequency       | Max Speed | Compatibility                |
| ---------------------- | --------------- | --------- | ---------------------------- |
| **802.11b**            | 2.4 GHz         | 11 Mbps   | Oldest, slowest              |
| **802.11g**            | 2.4 GHz         | 54 Mbps   | Works with 802.11b           |
| **802.11n**            | 2.4 GHz / 5 GHz | 600 Mbps  | Backward compatible with b/g |
| **802.11ac**           | 5 GHz           | 1 Gbps+   | Works with n (5 GHz)         |
| **802.11ax (Wi-Fi 6)** | 2.4 GHz / 5 GHz | 9.6 Gbps  | Supports all previous        |

---

### **⚠ What Happens If a Device Doesn’t Support the Network?**

- If your router is set to **only allow** 802.11n or 802.11ac, **older devices (b/g) won’t connect**.
- To allow older devices, enable **Legacy Mode** on the router.

---

### **🛠 Enabling Legacy Mode for Compatibility**

1️⃣ **Log into your router** (via `192.168.1.1` or `192.168.0.1`).  
2️⃣ **Go to Wireless Settings** → Look for **Wi-Fi Mode / Network Mode**.  
3️⃣ Set it to **Mixed Mode (b/g/n)** or **Legacy Mode** to allow all devices.  
4️⃣ Save settings & reboot the router.

This ensures that older **b/g devices can connect**, but might **reduce overall network speed**. 

---
### How do I add new Devices?

- **Access Control**: Decide who can connect based on network usage needs.
- **Guest Access**: Some routers allow a **separate SSID** for guests.
- **Restrictions**: Guests can access **only the internet**, not local devices.
- **Security Benefit**: Keeps the **main network private & secure** while allowing visitors to connect.
