# Client and Server

**HOST**: All computers connected to a network that participate directly in network.
In modern networks, computer hosts can act as a client,a server or both.

- ==**SERVER**:== Hosts that have software installed which enables them to provide info like email, web pages.
- Each service requires separate server software. E.g . a host requires web server software in order to provide web services to the network.

- ==**CLIENT**==:  Computer Hosts that have software installed that enables the request and display the ingo obtained from the server. E.g web browser like chrome.

**TYPE** 
1. Email: email server runs email server software.Client uses mail client software such as microsoft outlook.
2. Web: Web server runs web server software.Client uses browser such as internet explorer to access web pages.
3. File : The file server stores corporate and user files in  a  central location. Client access them with client software such as File explorer.

### Peer to peer Network(P2P)
- One computer run both **client** and **server** software. at the same time.
- Minimum requirement of 2 devices either with wired or wireless connection .
- Multiple PCs can be connected to create a larger p2p network, it requires a network device such as a switch , to interconnect computers.
- Main disadvantage: performance slow , if acting as both client and server.
- In Large network, dedicated severs are necessary to support no of service requests.
- **advantages**:
     - Easy to set up.
     - Less Complex.
     - Low cost coz network devices and dedicated servers may not be required.
     - Can be used for a simple task such as transferring files and sharing printers.
 - **Disadvantages**:
      - No centralised administration.
      - Not as secure.
      - Not scalable.
      - All devices may act as  both client and servers which can slow their performance.

## PEER TO PEER APPLICATIONS

- A P2P application alllows a device to act as both a client and a server within same communication.
- Every client is a server and vice versa.
- In a **hybrid P2P system**, files or resources are still shared **directly between peers**, but there is a **centralized index server** that helps locate those resources.

How it works:

1. A peer asks the **index server** where a specific file is located.
2. The index server checks its list and tells the peer which other peer has the file.
3. The peer then directly connects to the other peer to download the file.

This system combines **centralized searching** (faster lookups) with **decentralized sharing** (no need for a central file server). Examples include **BitTorrent (tracker-based) and eMule (server-assisted P2P).**

A computer with server software can provide services simultaneously to one or many clients, as shown in the figure.

Additionally, a single computer can run multiple types of server software. In a home or small business, it may be necessary for one computer to act as a file server, a web server, and an email server.

A single computer can also run multiple types of client software. There must be client software for every service required. With multiple clients installed, a host can connect to multiple servers at the same time. For example, a user can check email and view a web page while instant messaging and listening to internet radio.
