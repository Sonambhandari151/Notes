## Data Transmission
types of personal data:

- **Volunteered data -** This is created and explicitly shared by individuals, such as social network profiles. This type of data might include video files, pictures, text, or audio files.
- **Observed data -** This is captured by recording the actions of individuals, such as location data when using cell phones.
- **Inferred data -** This is data such as a credit score, which is based on analysis of volunteered or observed data
The term bit is an abbreviation of “binary digit” and represents the smallest piece of data. Each bit can only have one of two possible values, 0 or 1.



# 1.2.2 The Bit 

- All data is stored and processed as binary code.
- Commonly used code (**ASCII: American State Code for Information Interchange**), each character is represented by 8 bits. E.g.
     - A: 01000001
    Group of 8 bits : **byte**

# 1.2.3 Common Methods of Data Transmission
- After data is transformed into a series of bits, it must be converted into signals that can be send across the network media(copper wire, fiber-opt) 
There are three common methods of signal transmission used in networks:

- **Electrical signals -** Transmission is achieved by representing data as electrical pulses on copper wire.
- **Optical signals -** Transmission is achieved by converting the electrical signals into light pulses.
- **Wireless signals -** Transmission is achieved by using infrared, microwave, or radio waves through the air.

Most homes and small businesses use **copper wires(cables) or Wi-Fi enabled wireless connections** for network signals.
- Large networks employ **fiber-optic cables** for longer distances.

# Bandwidth
- Rate of Data transfer.
- Capacity of a medium to carry data.
- **Digital Bandwidth** : amount of data flow in a given amount of time.
- Bandwidth is typically measured in the no of bits that can be sent across the media in a second.
- Common Bandwidths
     - Kbps, Mbps(Millions of bits per sec), Gbps(Billions).
- Fundamental unit of bandwidth: bits per sec(bps).

# Throughput
- Measure of bits transfer over a given period of time.
- Don't usually match the specified bandwidth. Factors:
     - Amount of data being sent and received over the connection.
     - Type of data.
     - The latency created by no of network devices encountered b/w source & destination( processing & forwarding delays).
- Doesn't check if the data is useful or not.
- some transmitted data includes control messages used for network management, not just user data.
- Throughput is always **less than or equal to the slowest link's bandwidth**, but other factors can make it even slower.


**Difference from Bandwidth:**

- **Bandwidth** is the maximum data capacity of a network (like a highway's total lanes).
- **Throughput** is the actual data transfer rate (like the number of cars moving on the highway).
