## proxy

**proxy** is an intermediary server that sits between a client (user) and the internet. It forwards requests and responses, acting as a gateway.

### **Types of Proxies:**

1. **Forward Proxy** – Used by clients to access external resources (e.g., web proxies in corporate networks).
2. **Reverse Proxy** – Sits in front of web servers to handle requests, improve security, and load balancing.
3. **Transparent Proxy** – Intercepts traffic without user awareness, often used in filtering and caching.
4. **Anonymous Proxy** – Hides the client’s IP address to maintain privacy.
5. **High-Anonymity Proxy** – Frequently changes IP addresses to enhance anonymity.

NAS is a file-level storage system that connects to a network, allowing multiple users and devices to access shared files over a standard Ethernet connection. It uses protocols like NFS, SMB, and CIFS for file sharing. NAS is commonly used for file storage, backups, and media streaming.

SAN is a high-speed, block-level storage network that provides direct access to storage devices for servers. ## spine and Leaf Architecture
  is a modern **data center network design** that improves speed, scalability, and redundancy.

### **Structure:**

🔹 **Leaf Layer** (Access Layer)

- Connects to servers, storage, and network devices.
- Each leaf switch connects to **all spine switches**.

🔹 **Spine Layer** (Core Layer)

- Connects all leaf switches, ensuring **low-latency, high-bandwidth** connections.
- No direct connections between spine switches.

### **Advantages:**

✅ **Low Latency** – Traffic takes only one or two hops.  
✅ **High Redundancy** – Multiple paths prevent failures.  
✅ **Scalability** – Easily add more switches without congestion.

🚀 **Used in cloud data centers and high-performance networks!**

## VXLAN
VXLAN (Virtual Extensible LAN) is a network virtualization technology that encapsulates Layer 2 Ethernet frames into Layer 3 UDP packets. It allows for the creation of virtualized Layer 2 networks over a Layer 3 infrastructure. VXLAN is commonly used in data centers to extend networks across geographically distributed locations, providing scalability and isolation for virtual machines (VMs) or containers.

Key features of VXLAN:

- **Overlay Network**: VXLAN creates an overlay network on top of an existing IP network.
- **Scalability**: It supports up to 16 million unique VXLAN segments, providing large-scale network virtualization.
- **Encapsulation**: VXLAN encapsulates Ethernet frames in UDP packets, allowing communication across Layer 3 boundaries.
- **Multitenancy**: It provides network isolation for different tenants in a multi-tenant environment.
