- pip list: lists all tools installed
- pip list -o/--outdated: tools for upgrade
- pip freeze > requirements.txt : suppose working on a project , & you need to share list of packages they need
- cat reqirements.txt
- pip install -r file.txt: install all required packages from file.txt
- To install all packages together: 
```
pip freeze --local | grep -v '^\-e' | cut -d = -f 1 | xargs -n1 pip install -u 
```
