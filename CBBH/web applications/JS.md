
- **Purpose**: Widely used for **web** and **mobile development**.
    
- **Role**: Primarily a **front-end language** executed in the browser, but also used on the **back-end** with **Node.js**.
    
- **Compared to HTML/CSS**:
    
    - **HTML/CSS** = structure and style.
        
    - **JavaScript** = functionality and interactivity.
        
### **Basic Syntax**

- **Embedding Code**:
    
    ```html
    <script type="text/javascript">
      // JS Code
    </script>
    ```
    
- **External File**:
    
    ```html
    <script src="./script.js"></script>
    ```
    
- **Example**:
    
    ```javascript
    document.getElementById("button1").innerHTML = "Changed Text!";
    ```
    

---

### **Usage**

- Adds **interactivity** to static HTML/CSS.
    
- Common functions:
    
    - Real-time content updates
        
    - User input processing
        
    - Animations
        
    - `JavaScript` is also used to automate complex processes and perform HTTP requests to interact with the back end components and send and retrieve data, through technologies like [Ajax](https://en.wikipedia.org/wiki/Ajax_\(programming\)).
        
- **Client-side execution**: Fast and does not require reloading from server.
    

---

### **Tools**

- [JSFiddle](https://jsfiddle.net/): Online platform to test and share HTML, CSS, and JS code.

### 📘 **JavaScript Frameworks – Notes**

- As web applications grow in complexity, using **pure JavaScript** becomes inefficient.
    
- Frameworks help simplify and speed up **development**.
#### 🔹 **Purpose of Frameworks**

- Provide **pre-written libraries** to handle common tasks.
    
- Enable easy creation of advanced features like:
    
    - **User login**
        
    - **User registration**
        
    - **Dynamic content rendering**
        

#### 🔹 **Dynamic HTML**

- Frameworks allow **HTML to update dynamically** based on data or user interaction.
    
- Reduces the need for **static HTML** updates.
    

#### 🔹 **How They Work**

- Most frameworks are built in **JavaScript** or are **compiled into JavaScript**.
    
- Examples of such frameworks:
    
- [Angular](https://www.w3schools.com/angular/angular_intro.asp)
- [React](https://www.w3schools.com/react/react_intro.asp)
- [Vue](https://www.w3schools.com/whatis/whatis_vue.asp)
- [jQuery](https://www.w3schools.com/jquery/)
