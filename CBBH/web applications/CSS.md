
## 🟦 Cascading Style Sheets (CSS) – Notes

### 📌 Definition

- **CSS** (Cascading Style Sheets) is a **stylesheet language** used with HTML to define the **look and formatting** of elements on a webpage.

### 🧱 **Syntax**

```css
selector {
  property: value;
}
```

Example:

```css
body {
  background-color: black;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: helvetica;
  font-size: 10px;
}
```
### 🔹 **How CSS Works**

- Styles can be applied to **elements**, **classes**, or **IDs**.
    
- Multiple styles can be grouped in a **.css** file.
    
- CSS controls layout, color, fonts, spacing, positioning, etc.
    

| Property            | Description                  |
| ------------------- | ---------------------------- |
| `color`             | Text color                   |
| `background-color`  | Background color             |
| `font-size`         | Size of text                 |
| `font-family`       | Typeface                     |
| `margin`, `padding` | Space outside/inside element |
| `text-align`        | Text alignment               |
| `border`            | Border styling               |
| `height`, `width`   | Element dimensions           |

### 🌀 **Animations in CSS**

- CSS supports powerful **2D/3D animations** using:
    
    - `@keyframes`
        
    - `animation`
        
    - `animation-duration`
        
    - `animation-direction`
        
- Can be used to create effects like **parallax**, **hover animations**, and **sliders**.

### 🤝 **CSS + JavaScript**

- JS can dynamically modify CSS (e.g., change styles on user interaction).
    
- Used together for **responsive** and **interactive** UI.
### 🧩 **CSS in Other Technologies**

- Can style **XML** and **SVG**.
    
- Used in **mobile UI design** (e.g., React Native).
