- Not a physical connection.
- logical connection that's used by programs and services to exchange info.
- Determines which program or services on a computer or server to be used.
- Have a unique number that identifies them.(0-65535)
-  80,443- web pages(HTTP,HTTPS)
- 21-FTP
- 25-Email(SMTP)
- A port is always associated with an IP address.
- IP address determines the location of that server.
- A port number determines which service or program on that server it wants to use.
 
---
**NETSTAT**
- network statistics
- Command line tool that is used to display the current network connections and port activity on your computer.
- for cmd --> netstat -n
- FTP- to transfer files over a network.
- Uses port 21
- They are assigned by IANA(Internet assigned Numbers Authority).
- port numbers are broken down into 3 categories.
- (0-1023) -> SYSTEM or WELL-KNOWN PORTS.
- (1024-49151) -> USER or REGISTERED ports.
- registered by companies and developers for a particular service.
- (49152-65535) -> Dynamic or Private ports.
- Client -side ports that are free to use.
- these are ports that your computer assigns temporarily to iteself during a session.
- eg- when viewing a web page
- first two types of ports- server based
- last- client based 
-   port 80 - HTTP
- port 443 - HTTPS (secure)
